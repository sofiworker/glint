# HTML 原型入口

直接打开 `index.html`，无需构建或本地服务器。顶部条只是原型导航，不是正式产品的主窗口。

建议顺序：

1. 首次引导：欢迎、热键、默认完成动作、外观、演练、收起托盘。
2. 常驻 → 模拟热键 → 拖动框选 → 箭头 / 遮盖 / 文字 → 撤销重做 → 复制完成，直接返回桌面。
3. 截图浮层 → 贴图，拖动标题栏、调节透明度，从“···”或右键查看操作与穿透救援。
4. 设置：13 个分类，修改明暗主题 / 强调色、录入快捷键、保存 / 放弃 / 恢复默认、离开未保存确认。
5. 异常反馈：冲突、捕获失败、权限拒绝、复制失败、保存失败、内存预算与贴图救援。

`F1` 是浏览器内的演示截图入口，`Esc` 取消，截图选区内 `Enter` 执行设置的默认完成动作。工具条“复制完成”始终代表复制并离开；它和 Enter 的可配置默认动作分开。系统热键未注册。

设置保存在当前浏览器 localStorage，可通过“恢复默认”再保存重置。文件 URL 的存储隔离依浏览器而异。页面不请求网络，不读取真实桌面、剪贴板或用户文件；保存 / 复制 / 权限均为模拟。

已绘制对象支持撤销与重做，选区支持移动 / 手柄调整；既有单个标注对象的选中后编辑尚未在 HTML 中模拟。部分设置仅呈现原生产品配置规划（例如 UI 缩放、子元素检测、输出格式），不表示 HTML 已实现系统能力。OCR / 录屏只展示后续流程说明。

详细本地产品约束、路线、验收与旧验证参考见项目 `.local/notes/`，该目录已 Git 忽略。本轮停留在原型与工程准备阶段。

## 截图工具条自定义

设置 → 截图 → 自定义工具条，或直接点击设置导航“截图工具条”。截图时点击工具条自定义图标或右键工具条，也可在保留当前选区和标注的情况下调整。

- 图标＋文字 / 仅图标，图标有名称提示与无障碍标签。
- 工具勾选显示、拖动排序或上移 / 下移；选区、取消、复制与自定义入口始终保留。
- 隐藏工具收入“更多”，依然可以选用。
- 工具 / 撤销重做 / 完成动作分组线可开关。
- 跟随选区自动避让 / 固定顶部 / 固定底部。
- 设置页即时预览后保存；浮层自定义支持应用、取消和恢复默认，应用后保留现有标注。
- 属性区按所选工具变化：线条工具的颜色与线宽、文字提示、实心遮盖 / 像素化切换、取色说明。

这些配置会保存在原型的浏览器本地存储中。刷新旧页面后即可看到新增入口，未开发原生业务。

## 语言与地区

首次引导和设置 → 常规均可选择“自动 / 跟随系统”、简体中文、English。首次打开按浏览器首选语言列表匹配；未找到已支持语言时回退英语并提示。手动选择优先，引导即时记忆，设置页需保存；取消修改恢复已保存语言。日期时间遵循浏览器地区偏好，与界面语言分离。

当前只提供简体中文与英语翻译，其余语言及 RTL 布局为后续计划。HTML 使用 navigator.languages 演示检测，原生版后续读取 Windows / macOS / Linux 系统语言偏好。本次没有开始原生业务开发。
