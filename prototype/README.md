# HTML 原型入口

直接打开 `index.html`，无需构建或本地服务器。顶部条只是原型导航，不是正式产品的主窗口。

截图后浮窗与编辑预览：打开 `postprocess.html`，或从顶部“截图后编辑”进入。用户最终明确的默认流程是：现有快捷键与截图浮层 → 完成截图即复制到剪贴板 → 返回桌面并显示不抢焦点的缩略浮窗 → 需要时点击缩略图进入独立后处理 → 修改后再次复制。浮窗关闭不清空剪贴板；后处理不作为粘贴之前的必经步骤。该页面默认展示“截图后”的桌面和浮窗，点缩略图才展示编辑界面；另有录屏结束后的预览入口。

浮窗点击后直接编辑对应的单张截图或单段视频（v7），不经过文件列表，也没有“本次打开”栏。编辑窗口采用项目现有主题色与控件尺度：标题栏为当前内容、复制和保存副本；下方为撤销/重做及裁剪、标注、文字、遮盖、调整；工具选项紧接其下。画布占据主要区域，不常驻左右侧栏。视频额外显示底部画面与标注时间线。它是 M3/M6/M8 可选后处理提案；未改动现有 `app.js` 的截图输出与设置行为，对应原生实现和验证范围见项目 README 与 `.local/notes/POSTPROCESS-NATIVE-2026-11-17.md`。

图片交互包括：滚轮缩放/适应/空格拖动画布，单击对象选择、拖动/手柄缩放，双击文字在画布内编辑（Enter 完成、Esc 取消），颜色/线宽随所选对象显示。裁剪的范围与旋转/翻转作为同一草稿，应用后形成一次撤销，取消或退出工具恢复草稿前状态。原图对比按住显示、松开恢复；亮度/对比度/饱和度在工具选项区调整。尺寸、标注对象列表、打开其他文件收到“更多”，打开其他文件替换当前内容，有未保存修改时提示，取消或读取失败保留当前编辑。

视频交互包括：本地视频帧预览、时间定位、左右键逐帧步进与空格播放/暂停、片段分割/删除及后续片段接续、片段起止点、标注出现/结束时间、音量/静音设置；删除片段时示例标注时间随之收缩。选中片段/标注后，选项在同一顶部区域切换。导出对话框区分 PNG/JPEG/WebP/BMP/TIFF 与 MP4/GIF，并展示尺寸、质量、H.264/H.265、AAC/无声音和帧率。H.265 在原生版通过本机编码检测后可选；GIF 无声音且最高 30 FPS；WebP 无损。导出重新生成像素，不携带源文件元数据。仅在内容有修改时关闭才提示，复制保持编辑窗口。聊天预览可通过宿主设计控件调整主题和强调色。本轮工作台文案为中文，完整双语适配仍需补齐。

截图遮罩工具条已另行替换为上述简洁外观，并同步 Slint 原生及工具条自定义中的预览：圆角表面、无边框图标、当前工具浅强调色、完成按钮纯图标且使用强调色。不显示“复制”文字，保留名称提示与无障碍标签；按钮动作、顺序/显示配置、快捷键、选区定位、撤销重做和配置的默认完成动作不变。仅修正 HTML 单行槽宽计算，避免尾部按钮只露出一部分。

品牌标志统一使用 `assets/brand/` 的靛蓝底取景框图形，托盘使用小尺寸版本。界面操作图标统一使用 [Lucide](https://lucide.dev/icons/categories) 的本地 SVG（lucide-static 1.77.0，24×24、2px 描边、圆角端点）。`assets/icons/lucide/manifest.json` 保存版本、校验和及语义映射；`python tools/sync_icons.py` 同时生成原型 `icons.js` 和原生 SVG，修改后使用 `--check` 校验同步。上游 ISC/MIT 许可保留于 `assets/icons/lucide/LICENSE.txt`，运行时无需联网或图标字体。

页面起始为示例素材；用户主动选择本地文件后，浏览器可读取图片或视频元数据并显示预览，不上传，也不持久化素材。视频示例播放只推进游标，本地视频预览通过源时间定位帧，不代表完整连续播放或音频混合引擎。裁剪、滤镜、像素化、时间线与标注仍是交互规格；复制和导出明确提示未写系统剪贴板/未生成文件。未实现原生后处理引擎、真实像素合成与视频/GIF 编码、自动跟踪遮盖、工程持久化或完整双语适配。详见 `.local/notes/POSTPROCESS-UI-2026-11-16.md`。

建议顺序：

1. 首次引导：欢迎、热键、默认完成动作、外观、演练、收起托盘。
2. 常驻 → 模拟热键 → 拖动框选 → 箭头 / 遮盖 / 文字 → 撤销重做 → 复制完成，直接返回桌面。
3. 截图浮层 → 贴图，拖动标题栏、调节透明度，从“···”或右键查看操作与穿透救援。
4. 设置：13 个分类，修改明暗主题 / 强调色、录入快捷键、保存 / 放弃 / 恢复默认、离开未保存确认。
5. 异常反馈：冲突、捕获失败、权限拒绝、复制失败、保存失败、内存预算与贴图救援。

`F1` 是浏览器内的演示截图入口，`Esc` 取消，截图选区内 `Enter` 执行设置的默认完成动作。工具条“复制完成”始终代表复制并离开；它和 Enter 的可配置默认动作分开。系统热键未注册。

主原型设置保存在当前浏览器 localStorage，可通过“恢复默认”再保存重置。文件 URL 的存储隔离依浏览器而异。主原型不读取真实桌面、剪贴板或用户文件；保存 / 复制 / 权限均为模拟。独立后处理页仅在用户通过文件选择器主动打开时读取所选本地文件。

已绘制对象支持撤销与重做，选区支持移动 / 手柄调整；既有单个标注对象的选中后编辑尚未在 HTML 中模拟。部分设置仅呈现原生产品配置规划（例如 UI 缩放、子元素检测、输出格式），不表示 HTML 已实现系统能力。OCR / 录屏只展示后续流程说明。

详细本地产品约束、路线、验收与旧验证参考见项目 `.local/notes/`，该目录已 Git 忽略。本轮停留在原型与工程准备阶段。

## 截图工具条自定义

设置 → 截图 → 自定义工具条，或直接点击设置导航“截图工具条”。截图时点击工具条自定义图标或右键工具条，也可在保留当前选区和标注的情况下调整。

- 图标＋文字 / 仅图标，图标有名称提示与无障碍标签。
- 工具勾选显示、拖动排序或上移 / 下移；选区、取消、复制与自定义入口始终保留。
- 隐藏工具收入“更多”，依然可以选用。
- 工具 / 撤销重做 / 完成动作分组线可开关。
- 跟随选区自动避让 / 固定顶部 / 固定底部。
- 设置页即时预览后保存；浮层自定义支持应用、取消和恢复默认，应用后保留现有标注。
- 属性区按所选工具变化：线条工具的颜色与线宽、文字提示、实心遮盖 / 像素化切换、取色说明。

这些配置会保存在原型的浏览器本地存储中。刷新旧页面后即可看到新增入口，未开发原生业务。

## 语言与地区

首次引导和设置 → 常规均可选择“自动 / 跟随系统”、简体中文、English。首次打开按浏览器首选语言列表匹配；未找到已支持语言时回退英语并提示。手动选择优先，引导即时记忆，设置页需保存；取消修改恢复已保存语言。日期时间遵循浏览器地区偏好，与界面语言分离。

当前只提供简体中文与英语翻译，其余语言及 RTL 布局为后续计划。HTML 使用 navigator.languages 演示检测，原生版后续读取 Windows / macOS / Linux 系统语言偏好。本次没有开始原生业务开发。

视频导出原型已覆盖 MP4、GIF、MOV、MKV、WebM；MOV/MKV 对应 H.264/H.265 + AAC，WebM 对应 VP9 + Opus，GIF 隐藏编码和音频选项。MOV/MKV/WebM 在原生版按本地 FFmpeg 组件及实际短片检测结果开放；HTML 只演示选择行为，不生成文件。
