# Motion-aware Fluent subset

Derived from Slint v1.18.1 internal/compiler/widgets, matching the exact Cargo pin. Fluent Button, CheckBox, ComboBox, Slider, ScrollView and shared components/styling, plus common ComboBoxBase/SliderBase, retain their upstream copyright and SPDX statements. Glint selects GPL-3.0-only; full text is ../../../../LICENSE. See the repository THIRD-PARTY-NOTICES.md. The unchanged Fluent SVGs are Copyright (c) 2020 Microsoft Corporation, MIT; see LICENSE-MIT-Fluent-icons.txt and individual .license files. UPSTREAM-REUSE.toml preserves the upstream asset declaration.

Glint modifications (2026-10-19): animation durations use the component-local Motion.reduced policy; visual properties bypass lazy animated proxies when reduced, stopping visible in-flight interpolation immediately (duration changes alone do not stop running Slint animations); unused animations with no local binding were removed; public standard Palette supplies color scheme and accent in place of SlintInternal; the ComboBox array lookup is a pure Rust callback retaining first-match/unknown-value semantics; ScrollView removes experimental @shadowable/@deprecated annotations while retaining content/viewport aliases. Glint uses those aliases without declaring shadows. LineEdit now uses the same opaque semantic palette as other controls. Its upstream TextInput base preserves IME, selection, clipboard, undo and context menus; interface aliases are explicit to avoid experimental syntax, and unused password/clear icon buttons are omitted. Layout boxes remain upstream standard widgets. Text caret, user-driven scrolling, selection and drag rendering remain functional.

No experimental compiler flag, registry patch, custom runtime, background timer or dependency added. Configure the exported Motion global on each top-level component before use; this installs the lookup callback and presentation snapshot. Globals are per top-level component, not process-wide. On Slint upgrades, re-audit upstream diffs, public palette equivalence, new animations, controls/accessibility and licensing; run focused motion frames plus the full resident regression.

Component extraction (2026-10-22): moved unchanged assets and licensing into glint-ui; Motion.fast/normal now supply animation durations without changing defaults or reduced-motion bypass behavior.

Lucide unification (2026-11-20): `fluent/styling.slint` now maps every Icons property to the shared GlintIcons assets. The historical Microsoft SVGs and their notices remain for provenance, with no active control references. Added the Slint v1.18.1 Fluent SpinBox and unchanged common SpinBoxBase so numeric-input arrows use the same Lucide chevrons; removed its unused icon-color animation (the color has no state-dependent binding). Application CheckBox and SpinBox imports now use this local widget module. Lucide licensing and pinned source are in `assets/icons/lucide/` and the root THIRD-PARTY-NOTICES.md.

Compact numeric controls (2026-11-20): SpinBox places its Lucide steppers in a 20px vertical column and reserves the remaining width for text, matching the prototype's numeric fields. This fixes 74–76px controls whose previous two horizontal 28px steppers squeezed the value to zero width. The native workbench regression checks actual value text bounds and selected video timing/playback at narrow sizes, both languages and multiple software rendering scales.
